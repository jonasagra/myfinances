# MyFinances

Desktop personal finance app for Windows (C#, .NET 10, WPF, SQLite).

- Income and expense tracking with categories and monthly dashboard
- Brazilian labor simulators: INSS, IRRF, 13th salary, vacation, termination, overtime, payroll loans
- Loans with amortization schedules and late payment rules
- Payslip and spreadsheet import
- Local encrypted data, PIN protection and automatic backups

> Status: in progress. The source in `src/` was reconstructed from a compiled build, so some files are compiler-generated and will be cleaned up over time.
